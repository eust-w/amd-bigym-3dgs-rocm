# Image provenance and license

The PNG and GIF files in this directory are modified research-result previews,
not source frames copied from the dataset. Files at the directory root document
the historical A800 composite and cleanup. `gfx1100/reconstruction-*` and
`gfx1100/shell-*` are derived OpenSplat renders of the DL3DV scene.
`gfx1100/bigym-native-*` contains procedural native BiGym/MuJoCo frames and does
not contain a 3DGS background. The execution report labels these boundaries
explicitly.

- Source dataset: DL3DV-10K
- Scene hash: `951f9db189a7023708b7798e147e04048a84ce039c5761e8ecb1aa65dcb2da86`
