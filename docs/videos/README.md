# Runtime reference video

`bigym-3dgs-shell-reference.mp4` is the 31.45-second, `1696x960`, H.264
reference supplied by the project owner on 2026-08-04. It shows the BiGym
robot, dishwasher workbench and 3DGS kitchen background in simultaneous head,
left-wrist, right-wrist and external views.

The GitHub copy removes no frames, contains no audio, and was re-encoded with
H.264 CRF 24 plus fast-start metadata to remain below the repository's 10 MiB
media gate. It is a visual integration reference only and is not a substitute
for the separate AMD replay and 32-episode collection acceptance gates.
